Why it matters

routes ended in a crash for a textbook self-driving planner in Gurgaon traffic. In orderly traffic, —.

We drove the same standard planner over the same routes twice: once in orderly, lane-keeping traffic and once in Gurgaon traffic. Software tested only in orderly traffic is not ready for Indian roads, and this is a free way to find out before a car does.

For AV teams

Use it in Python.

A Gymnasium environment that works with the reinforcement learning tools you already use. It follows the conventions of highway-env and MetaDrive, and scores planners the way nuPlan and CARLA do.

# install
pip install "thirdeyelabs[sim]"

# drive
import gymnasium as gym
import thirdeye_sim.env

env = gym.make("ThirdEye/Gurgaon-v0")
obs, info = env.reset(seed=0)
obs, reward, terminated, truncated, info = env.step(env.action_space.sample())

# score a planner, and check the traffic against our footage
python -m thirdeye_sim.evaluate
python -m thirdeye_sim.realism
